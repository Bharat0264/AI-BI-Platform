# A simple guide to AURA-BI

## 1. Start with a file

Open **Start**. Choose a CSV, Excel or JSON file and click **Upload file**. If you do not have a file ready, click **Try sample data**. After loading, the site takes you to Results. Your original file is not edited.

The current public demo is shared. Use sample data: other visitors can see or replace data in that demo workspace.

## 2. Check your file when needed

Open **My data** to preview rows and see what the columns mean. For example, Quantity means units, Region means a place, and Order ID is a reference. The site suggests meanings; change a meaning only if it is wrong. Expand “Why this choice?” if you want the technical explanation.

## 3. Explore the results

Open **Results**. A financial file with sales, profit and dates gets financial charts. Other files get row/column checks and a number summary. The summary shows observed minimum, maximum and average values; it is not a prediction. Reference IDs, dates and category codes are excluded. Display values are rounded to two decimal places.

Financial result filters are optional. They do not automatically filter questions on the Ask a question page.

## 4. Ask a question

Open **Ask a question**. Click one of the examples based on your own columns to fill the box, then click **Ask about data**. Examples might include a total, an average or a breakdown by a group.

If the question has two possible meanings, choose the column you intended. This avoids silently calculating the wrong thing. If it cannot be answered, the result explains what information is missing. You can optionally filter rows or compare dates before asking.

Calculation details, voice controls and saved meanings/history are optional expandable sections. You do not need to open them to ask a basic question.

## 5. Save your work

Open **Download**. Use **Download data (CSV)** to save a spreadsheet copy. A financial PDF is available only when the file has the required sales, profit and date information. If unavailable, the page explains why and keeps CSV download available.

## Where are the other features?

**More tools** contains forecasts, models, financial risks, custom calculations, saved work and research information. These are optional. **How it works** gives a short reminder of the main steps from any page.
